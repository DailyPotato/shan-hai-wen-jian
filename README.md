# 山海问剑

电脑浏览器中的俯视角动作修仙游戏。亲手操纵剑修，在六张地图中探索、斩妖、采集、炼丹与锻造，按灵根属性选择功法，通过秘境试炼和剧情选择，走完自己的问剑之路。

在线游玩：[山海问剑](https://dailypotato.github.io/shan-hai-wen-jian/)。推荐桌面端的最新版 Chrome、Edge 或 Firefox。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 瞄准 | 鼠标 |
| 挥剑 | 鼠标左键 |
| 闪避 | 空格 |
| 当前装备功法 | Q |
| 交互 / 采集 | E |
| 使用丹药 | R |
| 行囊 | B |
| 山海图 / 地图旅行 | M |
| 功法 / 研习 | K |
| 剧情 / 委托 / 手记 | J |
| 暂停 | Esc |

从左下角的青云观出发，靠近师尊、守卷人、商人、炼丹炉、铸剑台或传送阵按 E。先采集与历练，准备丹药和灵剑，再挑战苍牙狼王、千年木灵和天门守卫，逐步突破炼气、筑基、金丹与元婴。死亡后可重聚灵身，返回青云观。

## 山海与修行

| 地图 | 内容与进入要求 |
| --- | --- |
| 青云山海 | 原野、竹林与天门遗迹，主线的三位首领 |
| 赤霄荒原 | 筑基后探索火山高地，采赤焰砂，挑战赤霄炎君 |
| 北冥雪域 | 金丹后探索冰湖走廊，采寒晶，挑战北冥霜龙 |
| 青竹洞天 | 炼气可入，三重试炼，首通获得长春残卷与青竹灵剑 |
| 赤焰地宫 | 筑基可入，三重试炼，首通获得离火残卷与雷纹法印 |
| 玄冰水府 | 金丹可入，三重试炼，首通获得凝霜残卷与玄冰仙衣 |

在驿站的安全区域使用山海图旅行，或走到地图内的发光入口按 E。秘境可以退出后再继续；重复通关提供材料奖励，首通装备与残卷不会重复领取。每张地图的妖兽、掉落和采集冷却独立保存。

新角色拥有确定种子的灵根：凡、真、地、天、仙五种品级，以及金、木、水、火、土、风、雷、冰八种属性。品级影响气血、灵力成长与修为获取，属性与功法相合会影响伤害和灵力消耗。角色面板展示实际加成。

六门功法均可研习至三重，并装备一门作为 Q 技能：御剑诀发射飞剑，离火焚天造成火焰与灼烧，玄冰凝霜发射寒冰并减速，长春引灵恢复气血并缠根，九霄雷引连锁雷击，厚土镇岳提供护盾与地震。通过商人、剧情、委托和秘境获取残卷，以材料提升功法等级。

行囊包含八类材料、回春丹及其他消耗品、残卷，以及武器、法衣、护符三个装备部位。灵石、灵草、玄铁、灵木、赤焰砂、寒晶、妖丹和灵髓均可在世界中获取；十二种配方用于炼药和制作装备。装备属性与药物增益会实际影响战斗。

剧情包含六个章节，每章提供不同的选择及资源、装备或关系后果。七项委托覆盖采矿、秘境、首领、探索与功法研习。按 J 查看条件、领取一次性奖励，并在手记中查看已作出的选择。

游戏自动保存到当前浏览器的本地存储；可以在游戏中导出和导入存档。旧版存档会升级到新格式，并保留境界、淬炼、修为、材料与主线进度。无效的导入不会覆盖当前存档。浏览器清理站点数据会删除本地存档，导出的存档可保留在自己的电脑上。游戏无需登录，存档不发送到服务器。

## 本地运行与验证

需要 Node.js 22 或更新版本，无需安装依赖：

```sh
node server.cjs
```

打开 http://127.0.0.1:4173。可通过 `PORT` 环境变量修改端口。

```sh
node --check content.js
node --check engine.js
node --check renderer.js
node --check app.js
node --check server.cjs
node --test tests/*.test.cjs
```

`content.js` 定义地图、功法、物品、配方、剧情和委托；玩法逻辑、碰撞、战斗、资源消费、进度和存档验证由 `engine.js` 管理；`renderer.js` 负责 Canvas 场景；`app.js` 管理输入、界面、存档和音频。全部内容在浏览器中运行，不依赖后端服务。标题插画、剑修和松树为生成美术，地形、建筑、妖兽、光影与特效使用程序绘制。

测试包含一次从新存档开始的完整扩展通关：仅使用真实移动、攻击、闪避、采集和正常资源消费，探索六张地图，完成三处秘境的全部三重试炼，击败八位首领，完成六个剧情章节与七项委托，习得六门功法、研习御剑诀至三重并突破元婴。全程不注入坐标、气血、修为或材料，最终存档经过重新载入验证。
