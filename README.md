# 山海问剑

电脑浏览器中的俯视角动作修仙游戏。用鼠标瞄准，亲手操纵修士移动、挥剑、射箭、施法与闪避；在山海探索、斩妖、采集、炼丹、锻造，经营宗门，经历八个境界与不同的破境挑战。

在线游玩：[山海问剑](https://dailypotato.github.io/shan-hai-wen-jian/)。推荐桌面端的最新版 Chrome、Edge 或 Firefox。

从左下角的青云观出发。靠近人物、炼丹炉、铸剑台或传送阵按 E；先采集与历练，准备丹药和兵器，再挑战守关者。按 L 随时查看下一境的真实条件，在安全驿站或宗门突破。普通面板打开时游戏暂停；安全炉台、铸台与闭关面板可继续正常游戏时间，让工坊、修炼和生产自然推进。Esc 暂停，关闭丹炉可继续游历。

## 器物与固定品阶功法

灵剑左键进行近身扇形斩击，灵弓发射真正的远程箭矢，法杖发射带小范围溅射的灵弹。兵器从入门装备到高阶宗门器物均可亲手装备；切换武器会改变普通攻击。武器与道法相契时道术威力额外提高 15%，也可以持其他兵器施放原来选择的功法。

七个修炼方向各有黄、玄、地、天、仙五门独立法门，共三十五门功法与三十五种经卷。**每门功法的品阶固定，不能升品；只能研习重数，最高三重。** 更高品阶须取得另一门法门的经卷，再单独参悟与修习。不同法门具有实际的飞剑数量、集束或扇射、爆裂范围、定身时长、连雷目标、击退距离与作用范围差异。

| 方向 | 实际施法效果 | 相契武器 |
| --- | --- | --- |
| 御剑 | 多道飞剑与近身剑气 | 灵剑 |
| 灵弓 | 集束或宽幅箭雨，中央灵箭穿透 | 灵弓 |
| 火法 | 爆裂火球、灼烧与近身炎环 | 法杖 |
| 冰法 | 穿透冰片与减速 | 法杖 |
| 木法 | 回春疗伤、缠根定身与木伤 | 法杖 |
| 雷法 | 锁定目标并连锁雷击、麻痹 | 法杖 |
| 土法 | 护盾、震地与击退 | 法杖 |

黄阶经卷通过初始传承、商人、剧情、人物委托、探索与秘境获得；加入宗门赠送入门弓、杖和穿云箭诀经卷。玄、地、天、仙阶经卷在青云宗凭贡献与材料换取，分别要求筑基、金丹、元婴、化神；地阶还要求青竹首通，天阶要求赤焰首通，仙阶要求全部三处秘境首通。K 面板逐项显示来源、缺失条件、真实代价、耗灵、冷却和武器相契倍率。

Q 主法与 F 副法分别计冷却，必须选择不同法门。六秒内按照木 → 火 → 土 → 金 → 水 → 木施放相生属性，后一法威力提高 25% 并返还 6 灵力；冰按水计算。术道悟道可延长连携窗口并增加返灵。相生状态在界面中显示，冷却与连携状态随存档保存。

行囊包含八类灵材、回春丹及其他消耗品、经卷，以及武器、法衣、护符三个装备部位。灵石、灵草、玄铁、灵木、赤焰砂、寒晶、妖丹和灵髓均可在世界中获取；配方用于炼药和制作剑、弓、杖、法衣、护符。装备属性与药物增益实际影响战斗。

## 悟道与分阶段炼丹

按 L 切换悟道树。剑道、弓道、术道各有三个依次解锁的节点，消耗分别为 1、2、3 点，境界门槛为炼气、金丹、化神。悟道点来自七次破境、十二处遗迹的四段探索进度、三处秘境首通、悬赏/护脉/镇妖塔首通与三重雷劫，最多 20 点；重复通关不加点。九节点共需 18 点，长期保存，不能重复购买。

剑道提高剑普攻伤害、射程和攻速，末节点按实际伤害吸血，每次至多恢复气血上限 4%。弓道提高箭伤害、飞行速度和攻速，末节点让一支普攻箭最多命中两个目标。术道把相生窗口延长至 8 秒、减少 Q/F 耗灵并把相生返灵增至 10，还可提高普通灵材采集产量；探索奖励、妖丹、灵髓和战斗掉落不受采集加成影响。

新版默认炼丹采用真实控温流程：选择五种丹方之一和灵髓、赤焰砂、寒晶或灵木药引，投料只扣一次；萃取阶段调整四档炉火，在合适温区净化杂质，最后选择快凝或慢凝。温度稳定程度、净化与凝丹方式共同决定成品。普通、精制、上品药物具有不同实际药效，强药不会被随后使用的弱药覆盖，也不会反复叠乘。回春丹恢复气血与灵力，凝神茶恢复灵力，护体散减少承伤，赤阳丹增强攻击，通灵丹提高真实修为所得。

铸剑台可为兵器铸入锋锐、守御、聚灵或轻身纹：加热、控温、间隔锤炼，再选水、寒晶或灵木淬炼。有效锤击与温度决定品质，各纹路都有真实取舍，例如锋锐增加攻击并减少气血。重铸替换旧纹，不叠加；切换装备保留气血、灵力比例。

投料、控制与领取都要亲自回到相应炉台。离开后过程按游戏时间推进，Esc、关闭游戏和死亡期间冻结。V5及以前的进行中旧炉保留原料与原流程，结算旧产品一次后才开始新版炼制。

## 宗门经营、心法与历练

前往青云宗按 N 加入宗门，贡献来自真实历练，可兑换灵材、经卷与高级兵器。悬赏清剿妖修、护脉守护三波晶石防卫、镇妖塔五层战斗与层间祝福、九霄渡劫一至三重躲雷，分别从筑基、金丹、元婴、化神开启。实例独立保存，成功结算实际掉落后两秒返回宗门；失败需要主动退出。首通与重复奖励都有实际限制。

新版默认生产调度让药田、锻坊、藏经阁分别选择订单、数量与五行方位。每批真正开工才扣投入材料；匹配方位、上游相生、弟子灵根、人物协作、性情、疲劳和研究等级共同影响时间。平衡轮值、赶工、保养慢工的速度、材料成本与疲劳不同，疲劳达到阈值后弟子会轮休恢复。取消订单保留已付费的当前批次；满三批库存停产，领取后继续。研究最多三级，设施升级与换位须先处理已承诺的工作。旧档需要先领取旧成果，再启用调度。

三名弟子各有一个性情：勤恳、性急、游手好闲；八种可训导词条还包括一丝不苟、吃苦耐劳、心灵手巧、灵气亲和、重情重义。词条实际改变生产、疲劳与部分战斗属性。付出45灵石和1灵髓更换一个词条，不会叠加；两种特殊词条需要空空儿的相应处置。

K 的心法搭配可装两项真实战斗心法，围绕剑、弓、火、冰、雷、木构筑吸血、穿透、燃血回灵、冰盾、蓄雷与生息。L 的闭关允许稳修或冲修，控制导气与压力，质量改变破境准备或限时实战心得。暂停和死亡冻结过程，材料只扣一次，成果只领取一次。

三条山海路线分别经历三个真实站点：灵药古道的采药、拦路与护送，赤焰驿道的匪袭、货车与火灾，寒渊旧藏的冰阵、护送与稳定阵眼。每站选择改变敌阵、风险、投入或收益；需走到站点作出选择，使用普通战斗与闪避守住目标，不能只点按钮跳过。每站剩余战利品入账一次，通关两秒后回宗。四名原人物各有六次有前置条件的同行契约，接取后才计行动；完成关系可实际付费获得生产、修为、承伤或护送支援。


## 人物支线、道侣、天赋与存档

四张新地图各有三位独立形体与立绘的成年人物，共十二人、二十四条两段支线。斩妖、采集、踏访只记录接取后的实际行动；交付须回到发布人物附近并付出真实材料，奖励只能领取一次。J 显示地域支线链并追踪目标，M 可定位人物所在地图。

江月灵30岁，沈云笙28岁。各自两条支线完成后，通过真实赠礼达到好感门槛，再付出80灵石、2妖丹缔结唯一道侣。可以邀请或暂别同行；野外月灵每12秒恢复5%气血，云笙每12秒恢复8%灵力，已满时不消耗护持，百艺天赋可把冷却缩到9秒。

空空儿的追缴与赔债两条支线之后，只能选择一次处置：再垫20灵石让他改过，获得灵木与修为并解锁重情重义；或交由城卫裁决，获得45灵石与4玄铁并解锁一丝不苟。地图上的飞贼只有真实未被挡住的伤害才会偷灵石，每次至多12、每贼累计至多120；斩倒后通过实际战利品归还已记账的全部失窃灵石。

L 的天赋页包含武道、灵法、百艺三条路径，共十八个节点：实际改变气血、攻击、防御、速度、承伤、灵力回复、耗灵、火冰伤害、修为、采集、生产、疲劳与道侣护持。天赋点来自初始一点、境界及每完成三条新支线一点；完整通关最多16点，需作出搭配选择，按前置逐个领悟，不能把十八项全部同时买满。

四图的十二种怪物拥有不同身体和真实攻击：鼠群扑咬、飞贼突进偷取、墨刃扇射、巨蟹正面硬甲、海妖环射余音、海蛇翻浪、蝎针持续毒、镇卫蓄盾突撞、灰蛾夺灵自疗、云鹏俯冲、棱镜八向光刃、雷眼预告落雷。原赤霄与北冥的六种普通怪也重塑成火蜥、灯焰、熔炉、霜角鹿、狐灵与六臂冰魁，并使用各自攻击。


宗主凌云真人讲解问剑之路，长老顾清玄负责功法与搭配。八位原有山海人物继续保留独立外形、对话与用途：顾清玄、陆青禾、苏百草、燕孤山、裴九商、祝炎、白霁和青篁。首次交谈选择产生不同赠礼与交情，只可选择一次；四项人物委托只领一次，斩妖与采药委托只计接取后的真实行动。交易和人物服务消耗材料、遵循实际游戏时间冷却，交情可解锁稀有服务。

六个剧情章节提供不同资源、装备或关系后果；七项原有委托涵盖采集、秘境、首领、六张山海地图探索与功法研习。按 J 查看要求、领取一次性奖励，并在手记中查看已经作出的选择。

游戏自动保存到当前浏览器，可在暂停菜单导出与导入存档。v1至v6旧存档升级为v7，保留角色、资源、装备、原地图、NPC 交情、委托、故事与秘境进度。v3 中已经升品的旧法会映射到对应固定品阶法门，保留原重数、当前选法和已获得的强度，包括旧仙阶法；迁移不会强制改变原境界。宗门、设施、弟子、活动、探索、武器弹道、副法、悟道与炼丹状态也会保存。v4及以前迁移后悟道尚未参悟，已完成的真实历练会提供相应悟道点。旧协议先按其原目录验证；v1至v5初始化新版工坊、调度与历练关系，v6保留已赚取的全部过程与进度，新人物支线、道侣、天赋与训导记录均从空进度开始。

无效导入不会覆盖当前存档。清理浏览器站点数据会删除本地记录，导出文件可备份或转移到另一台电脑。游戏无需登录，存档不发送到服务器。
