# 山海问剑

电脑浏览器中的俯视角动作修仙游戏。用鼠标瞄准，亲手操纵修士移动、挥剑、射箭、施法与闪避；在山海探索、斩妖、采集、炼丹、锻造，经营宗门，经历八个境界与不同的破境挑战。

在线游玩：[山海问剑](https://dailypotato.github.io/shan-hai-wen-jian/)。推荐桌面端的最新版 Chrome、Edge 或 Firefox。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 瞄准 | 鼠标 |
| 当前武器普通攻击 | 鼠标左键 |
| 闪避 | 空格 |
| 主法 / 副法 | Q / F（筑基解锁副法） |
| 人物 / 采集 / 古迹交互 | E |
| 使用回春丹 | R |
| 行囊 / 使用 / 装备 | B |
| 山海图 / 地图旅行 | M |
| 功法传承 / 重数 / 主副法 | K |
| 剧情 / 委托 / 手记 | J |
| 修行与境界突破 | L |
| 宗门 / 历练 / 经营 / 兑换 | N |
| 暂停 / 关闭面板 | Esc |

从左下角的青云观出发。靠近人物、炼丹炉、铸剑台或传送阵按 E；先采集与历练，准备丹药和兵器，再挑战守关者。按 L 随时查看下一境的真实条件，在安全驿站或宗门突破。面板打开时游戏暂停，战斗和设施生产都暂停。

## 山海与修行

| 常驻地图 | 内容与进入要求 |
| --- | --- |
| 青云山海 | 原野、竹林与天门遗迹，主线的三位守关首领 |
| 赤霄荒原 | 筑基后探索火山高地，采赤焰砂，挑战赤霄炎君 |
| 北冥雪域 | 金丹后探索冰湖走廊，采寒晶，挑战北冥霜龙 |
| 青竹洞天 | 炼气可入，三重试炼，首通获得长春经卷与青竹灵剑 |
| 赤焰地宫 | 筑基可入，三重试炼，首通获得离火经卷与雷纹法印 |
| 玄冰水府 | 金丹可入，三重试炼，首通获得凝霜经卷与玄冰仙衣 |
| 青云宗 | 独立的安全宗门大院，包含宗主殿、传功、丹药、铸兵、藏经、灵材与破境设施 |

在驿站的安全区域使用 M 旅行，或走到发光入口按 E。每张常驻地图的妖兽、掉落和采集冷却独立保存；秘境可以退出后继续。原三处秘境各有三重真实战斗，首通的装备与经卷只领一次，重复材料奖励有次数上限。

青云山海、赤霄荒原、北冥雪域另有十二处探索机缘，包含营地秘匣、古碑和药畦。靠近按 E 查看门槛与不同奖励，领取一次后留下探索记录。

修行依次经过炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘。每境提高实际气血、灵力、攻击与移动能力。前三次突破保留苍牙狼王、千年木灵与天门守卫的首领要求；化神须完成镇妖塔五层，炼虚、合体、大乘分别须完成第一、第二、第三重雷劫。修为、材料和历练要求均可在 L 中查看。

新角色拥有确定种子的灵根：凡、真、地、天、仙五种品级，以及金、木、水、火、土、风、雷、冰八种属性。灵根品级影响气血、灵力成长与修为获取，属性与功法相契影响伤害和耗灵，角色面板显示实际加成。

## 器物与固定品阶功法

灵剑左键进行近身扇形斩击，灵弓发射真正的远程箭矢，法杖发射带小范围溅射的灵弹。兵器从入门装备到高阶宗门器物均可亲手装备；切换武器会改变普通攻击。武器与道法相契时道术威力额外提高 15%，也可以持其他兵器施放原来选择的功法。

七个修炼方向各有黄、玄、地、天、仙五门独立法门，共三十五门功法与三十五种经卷。**每门功法的品阶固定，不能升品；只能研习重数，最高三重。** 更高品阶须取得另一门法门的经卷，再单独参悟与修习。不同法门具有实际的飞剑数量、集束或扇射、爆裂范围、定身时长、连雷目标、击退距离与作用范围差异。

| 方向 | 实际施法效果 | 相契武器 |
| --- | --- | --- |
| 御剑 | 多道飞剑与近身剑气 | 灵剑 |
| 灵弓 | 集束或宽幅箭雨，中央灵箭穿透 | 灵弓 |
| 火法 | 爆裂火球、灼烧与近身炎环 | 法杖 |
| 冰法 | 穿透冰片与减速 | 法杖 |
| 木法 | 回春疗伤、缠根定身与木伤 | 法杖 |
| 雷法 | 锁定目标并连锁雷击、麻痹 | 法杖 |
| 土法 | 护盾、震地与击退 | 法杖 |

黄阶经卷通过初始传承、商人、剧情、人物委托、探索与秘境获得；加入宗门赠送入门弓、杖和穿云箭诀经卷。玄、地、天、仙阶经卷在青云宗凭贡献与材料换取，分别要求筑基、金丹、元婴、化神；地阶还要求青竹首通，天阶要求赤焰首通，仙阶要求全部三处秘境首通。K 面板逐项显示来源、缺失条件、真实代价、耗灵、冷却和武器相契倍率。

Q 主法与 F 副法分别计冷却，必须选择不同法门。六秒内按照木 → 火 → 土 → 金 → 水 → 木施放相生属性，后一法威力提高 25% 并返还 6 灵力；冰按水计算。相生状态在界面中显示，冷却与连携状态随存档保存。

行囊包含八类灵材、回春丹及其他消耗品、经卷，以及武器、法衣、护符三个装备部位。灵石、灵草、玄铁、灵木、赤焰砂、寒晶、妖丹和灵髓均可在世界中获取；配方用于炼药和制作剑、弓、杖、法衣、护符。装备属性与药物增益实际影响战斗。

## 宗门经营与历练

前往青云宗按 N 加入宗门，贡献来自真实历练，可兑换灵材、经卷与高级兵器。

| 宗门历练 | 解锁境界 | 玩法 |
| --- | --- | --- |
| 宗门悬赏 | 筑基 | 清剿近战、远射与重甲妖修 |
| 护脉守护 | 金丹 | 三波战斗保护灵脉晶石，晶石失守即失败 |
| 镇妖塔 | 元婴 | 五层不同敌阵，每层之间选择剑意、回元或凝神祝福 |
| 九霄渡劫 | 化神起 | 一至三重真实雷劫，躲避预告区域，在限定时间内存活 |

活动使用独立实例，活动中的敌人和掉落不会覆盖常驻地图。通关成功时奖励与剩余活动灵石自动入账，经过两秒游戏时间自动返回宗门；也可提前手动返回。塔层之间的祝福选择会等待玩家，失败后仍须手动退出。活动过程中也可主动退出。首通奖励与通关记录持久保存，重复奖励有上限，返宗倒计时随存档保存。

筑基后可建设灵药田、宗门锻坊与藏经阁，最多提升至三重，生产草木药材、玄铁赤焰砂、修为灵髓。陆青禾、沈炎明和林若水各有不同属性与招募条件，一位弟子同一时间只派驻一处设施。设施需要建成并派驻弟子才生产；调整五行方位与弟子相契会改变实际速率，界面显示每批时间、产出、倍率、容量与当前分工。

设施只按实际游戏时间生产，最多积存三批，满仓后停产，须回宗门主动领取。调整方位或调任弟子会重新开始当前批次；升级前须领取已有成果。死亡和暂停期间停产，关闭游戏不会产生离线收益。

## 人物、故事与存档

宗主凌云真人讲解问剑之路，长老顾清玄负责功法与搭配。八位原有山海人物继续保留独立外形、对话与用途：顾清玄、陆青禾、苏百草、燕孤山、裴九商、祝炎、白霁和青篁。首次交谈选择产生不同赠礼与交情，只可选择一次；四项人物委托只领一次，斩妖与采药委托只计接取后的真实行动。交易和人物服务消耗材料、遵循实际游戏时间冷却，交情可解锁稀有服务。

六个剧情章节提供不同资源、装备或关系后果；七项原有委托涵盖采集、秘境、首领、六张山海地图探索与功法研习。按 J 查看要求、领取一次性奖励，并在手记中查看已经作出的选择。

游戏自动保存到当前浏览器，可在暂停菜单导出与导入存档。v1、v2、v3 旧存档升级为 v4，保留角色、资源、装备、原地图、NPC 交情、委托、故事与秘境进度。v3 中已经升品的旧法会映射到对应固定品阶法门，保留原重数、当前选法和已获得的强度，包括旧仙阶法；迁移不会强制改变原境界。新增宗门、设施、弟子、活动、探索、武器弹道与副法状态也会保存。

无效导入不会覆盖当前存档。清理浏览器站点数据会删除本地记录，导出文件可备份或转移到另一台电脑。游戏无需登录，存档不发送到服务器。

## 本地运行与验证

需要 Node.js 22 或更新版本，无需安装依赖：

    node server.cjs

打开 http://127.0.0.1:4173。可通过 PORT 环境变量修改端口。

    node --check content.js
    node --check engine.js
    node --check renderer.js
    node --check app.js
    node --check server.cjs
    node --test tests/*.test.cjs

content.js 定义地图、功法、物品、配方、剧情、人物、宗门与活动；engine.js 管理碰撞、战斗、生产、资源消费、进度与存档验证；renderer.js 绘制 Canvas 场景；app.js 管理输入、界面、存档与音频。全部内容在浏览器中运行，无需后端。标题、宗门插画、剑弓杖修士与松树使用生成美术，地形、建筑、妖兽、光影和特效使用程序绘制。

测试包含三段真实游玩：从新角色探索原六图、清完三处秘境、八位首领、六章故事与七项委托并升元婴；从原样保留的真实 v2 档继续与八位人物交往、交付四项新委托并用已赚取材料研习火法；从原样保留的真实 v3 档继续探索十二机缘、经营三设施与三弟子、完成四类宗门历练、三重渡劫、升大乘并获得仙阶弓法三重。自然游玩测试只调用实际移动、战斗、闪避、交互与正常资源消费，不注入坐标、气血、修为、材料或贡献，最终存档重新载入验证。

独立机制测试另覆盖三十五门法的实际效果、固定品阶与购卷门槛、兵器攻击与弹道存档、副法冷却与五行连携、设施生产与容量、活动实例存档、早晚期突破条件、人物服务与非法存档拒绝。
