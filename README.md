# 山海问剑

电脑浏览器中的俯视角动作修仙游戏。亲手操纵剑修，在山野、竹海与遗迹中探索，以近战、御剑术和闪避击败妖兽，采集灵草与晶石，炼丹、锻剑并突破境界，最终挑战镇界守卫。

在线游玩：[山海问剑](https://dailypotato.github.io/shan-hai-wen-jian/)。推荐桌面端的最新版 Chrome、Edge 或 Firefox。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 瞄准 | 鼠标 |
| 挥剑 | 鼠标左键 |
| 闪避 | 空格 |
| 御剑术 | Q |
| 交互 / 采集 | E |
| 使用丹药 | R |
| 行囊 | B |
| 暂停 | Esc |

从左下角的山门出发，靠近师尊、炼丹炉、铸剑台和修行台按 E，管理修行和补给。在安全区域调息，探索世界获取经验与材料，再按目标提示依次挑战三位首领。死亡后可以重返山门。

游戏自动保存到当前浏览器的本地存储；可以在游戏中导出和导入存档。浏览器清理站点数据会删除本地存档。导出的存档可保留在自己的电脑上。游戏无需登录，存档不发送到服务器。

## 本地运行与验证

需要 Node.js 22 或更新版本，无需安装依赖：

```sh
node server.cjs
```

打开 http://127.0.0.1:4173。可通过 `PORT` 环境变量修改端口。

```sh
node --check engine.js
node --check renderer.js
node --check app.js
node --check server.cjs
node --test tests/engine.test.cjs
```

玩法逻辑、碰撞、战斗、资源消费、首领进度和存档验证由 `engine.js` 管理；`renderer.js` 负责 Canvas 场景；`app.js` 管理输入、界面、存档和音频。全部内容在浏览器中运行，不依赖后端服务。标题插画、剑修和松树为生成美术，地形、建筑、妖兽、光影与特效使用程序绘制。

测试包含一次从新存档开始的完整通关：仅使用移动、攻击、闪避、采集和正常资源消费，验证地图、装备、修为、三位首领与存档能够共同构成可完成的游戏循环。
